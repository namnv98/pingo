Đăng nhập

Tài khoản thật: password được hash (bcrypt) trước khi lưu ở server, không bao giờ lưu dạng thô. Đăng nhập/đăng ký xong server cấp 1 token, dùng token đó để xác thực WebSocket (không còn tự khai UUID nữa).

Bắt đầu trò chuyện

DM: chọn từ danh sách (chỉ hiện user đã đặt tên, trừ khi tick ô trên) hoặc dán user id trực tiếp. Group: để trống ô id + bấm "Tạo mới" nếu bạn là người tạo; bấm vào tên trong danh sách dưới ô "Thành viên" để thêm/bớt nhanh (đang chọn = tô xanh).
